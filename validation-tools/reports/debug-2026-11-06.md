## Confirmed defects and fixes

| Finding | Fix | Regression evidence |
| --- | --- | --- |
| Equal session updates invalidate observers and schedule saves | Mutate a local record and publish only changed values | 100 identical updates produce no observation callback; real changes still notify and update timestamps |
| Disabled RPC logs eagerly compute their strings | Lazy diagnostic arguments in Debug and Release | Disabled-log expression is never evaluated |
| Selected streaming cadence counts growing text despite a fixed interval | Lazy length calculation only for adaptive background cadence | Selected path never evaluates the counter; background path does |
| Answer deltas rewrite an unchanged thinking block | Track pending changes separately for assistant and thinking; clear at lifecycle boundaries | New fake-Pi test failed before the fix, passes afterward with the original thinking record unchanged |
| Message completion cancels the timer and drops pending thinking | Persist buffered thinking before clearing streaming state | New fake-Pi test failed both in memory and after reload before the fix; both assertions pass afterward |

Test infrastructure corrections:

- Three asynchronous formula tests now wait for the matching completion
  notification instead of assuming 150 ms is enough. The initial default suite
  failed the cache-invalidation test; the isolated suite passed before this
  correction, indicating scheduling sensitivity rather than a reproduced product
  rendering failure.
- The large-transcript attribution benchmark now varies its source per iteration.
  Its previous repeated source measured cache hits and could not substantiate
  first-render performance. Old and new numbers are not comparable speedups.
